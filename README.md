# Проектная работа «Сложно сосредоточиться»

Статичный одностраничный сайт, посвящённый теме концентрации внимания. Содержит информационные блоки с рекомендациями, галерею изображений и переключатель цветовой темы.

Структура проекта:

- `fonts/` — файлы шрифтов и подключение IBM Plex Mono
- `images/` — изображения для галереи
- `scripts/` — файлы JavaScript, отвечающие за переключение темы
- `styles/` — файлы стилей, разделённые по назначению

Важные файлы:

- `index.html` — HTML-файл главной страницы
- `scripts/script.js` — точка входа скрипта, управление переключением темы
- `styles/globals.css` — глобальные стили
- `styles/style.css` — основные стили компонентов
- `styles/dark.css` / `styles/light.css` — стили для тёмной и светлой темы

---

## Переключение темы

В шапке сайта реализован переключатель из трёх кнопок: «День», «Авто», «Неон». Выбранная тема сохраняется в `localStorage` под ключом `theme` и восстанавливается при повторной загрузке страницы.

Активная кнопка получает класс `header__theme-menu-button_active` и атрибут `disabled`.
